# House-Price-Prediction


This project uses machine learning regression algorithms to predict median house values using the California Housing dataset from Scikit Learn.

The goal is to explore housing data, train multiple regression models and experiment and find a model that provides accurate predictions.

## Models Implemented

- Linear Regression
- Decision Tree Regression
- Random Forest Regression
- Hyperparameter-tuned Random Forest

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Limitations

The model predicts area-level median house values, not individual property prices.

The original dataset target has a $500,000 upper cap.

Performance may differ on new data or outside California.

The test set was used during model comparison and experimentation, so the reported performance is not a completely untouched final estimate.
